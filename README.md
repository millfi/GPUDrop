# GPUDrop

ゲームキャプチャ動画のFPSを推定するアプリ。連続する2フレームをWebGPUシェーダで比較し、同一フレームを検出することで実効FPSを算出します。

## 概要

- **リアルタイム動作**: Mediabunnyによるハードウェアデコード+WebGPUによる高速比較
- **比較**: WebGPU compute shader で同一座標のピクセルを比較し、linearRGB空間でのユークリッド距離が閾値を超えたピクセル数を数える
- **同一フレーム判定**: 解析対象のうちピクセル閾値を超えた割合がフレーム閾値以下なら、重複フレームと判定
- **FPS**: 直近1秒間のユニークフレーム数を視覚化

## 使い方
[GPUDrop](https://millfi.github.io/GPUDrop/)にアクセス
## build & run
```shell
git clone https://github.com/millfi/GPUDrop.git
cd ./GPUDrop
npm install
npm run dev
```
を実行してnpmに案内されたlocalhostを開き、動画ファイルを選択します。読み込み後は先頭フレームを表示して一時停止します。その場で閾値・マスク・オーバーレイを調整し、プレイヤーのボタンで再生・一時停止・コマ送り・コマ戻しを操作します。
最後まで再生した後もシークできます。最終フレームで再生ボタンを押すと、先頭から再生します。
プレビューの再生バー右端にある全画面ボタン、または F キーで、映像とオーバーレイの全画面表示を切り替えられます。Esc キーでも元の表示に戻ります。入力欄の操作中は F キーのショートカットは無効です。

## エクスポート

- 現在の閾値・マスク・オーバーレイ・グラフ設定で、動画の全範囲を先頭から再解析してMP4に書き出します。
- 一時停止中も書き出せます。一時停止・シーク位置や、それまでの解析履歴は書き出し範囲・結果に影響しません。
- 読み込み直後から、全編の再生を待たずに書き出せます。完了・中断後は元の位置に一時停止したプレイヤーを復元します。
- 書き出し中は出力に関わる設定を変更できません。
- マスクはFPS解析から除外する範囲です。映像の黒塗りやマスク枠の焼き込みは行いません。
- 「マスクを追加」から複数の範囲を指定でき、番号ごとに削除または全解除できます。重なる部分は一度だけ除外します。解析対象がゼロになる追加は拒否し、別ファイルを読み込むとマスクをリセットします。
- 「プレビュー表示」は画面上の表示だけを切り替えます。書き出す要素は各要素のチェックボックスで指定します。

## 動作環境

SafariとFirefoxでは動かない可能性が高い。

## 操作

- **閾値**: 1ピクセルあたりのlinearRGB距離の許容値 (0〜0.5)。低圧縮の動画では小さく、強い圧縮では大きめに
- **差分パネル**: 閾値を超えたピクセルが赤で表示される
- **検知リスト**: 重複と判定されたフレームの動画内時刻 (秒、小数点以下3桁) と先頭からのフレーム番号

## 開発時の検証

- `npm test`: プレイヤー・設定固定・複数マスクの回帰テスト。
- `npx tsc --noEmit`: 型チェック。
- 開発サーバーの `/GPUDrop/tests/browser.html`: WebGPU/WebCodecs対応ブラウザで検証動画を生成し、実際のGPU比較、マスク付きMP4出力・再読み込み、画面の読み込みと書き出し後の再生を検証します。動画はメモリ内で処理し、保存ダイアログはテスト内で置き換えます。
